## Development Workflow Rule

After every code change or implementation step, you must always include a short summary and provide the local development URL so the user can immediately view the result.


If the project runs on a different port, detect the correct port from the project configuration (package.json, dev scripts, vite config, next config, etc.) and provide the correct localhost URL.

Example output format:

Summary of changes:
- Created new component
- Updated API route
- Fixed state management

To preview the changes open my localhost.
