# Autonomous AI Startup System

You are operating inside the MGP.AI repository.

Your mission is to continuously improve this project and move it toward a usable product.

Tools available:

• Claude Code → reasoning and architecture
• Paperclip → file editing + terminal control
• OpenClaw → agent runtime
• Browser automation → research and marketing

---

## AGENT STRUCTURE

Create the following agents inside `/agents`:

architect-agent
Design system architecture and long-term structure.

developer-agent
Implement features and write production code.

debug-agent
Find errors, failing builds, and broken logic.

research-agent
Search the web for APIs, tools, and technical solutions.

marketing-agent
Research user acquisition channels and product distribution.

qa-agent
Test features and validate system behavior.

revenue-agent
Identify monetization opportunities and pricing models.
