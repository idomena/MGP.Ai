## PROBLEM 1: APP CLOSES / SCREEN TURNS OFF DURING WORKOUT ⚠️

### Current Issue:

- When user presses “Start Workout” and finishes a set, the phone screen turns off after a few seconds
- This disrupts the workout flow and user experience
- App becomes unusable during rest periods

### Required Solution:

Implement **Screen Wake Lock API** to keep the screen active during workouts.

#### Implementation Steps:

1. **Add Wake Lock variables at the top of your JavaScript:**

```javascript
let wakeLock = null;
let isWorkoutActive = false;
```

1. **Create Wake Lock request function:**

```javascript
async function requestWakeLock() {
  try {
    if ('wakeLock' in navigator) {
      wakeLock = await navigator.wakeLock.request('screen');
      console.log('Wake Lock activated');
      
      // Re-acquire wake lock if page becomes visible again
      wakeLock.addEventListener('release', () => {
        console.log('Wake Lock released');
        if (isWorkoutActive) {
          requestWakeLock();
        }
      });
    } else {
      console.warn('Wake Lock API not supported');
      // Fallback: show message to user to keep screen on manually
    }
  } catch (err) {
    console.error('Wake Lock error:', err);
  }
}
```

1. **Create Wake Lock release function:**

```javascript
async function releaseWakeLock() {
  if (wakeLock) {
    try {
      await wakeLock.release();
      wakeLock = null;
      isWorkoutActive = false;
      console.log('Wake Lock released successfully');
    } catch (err) {
      console.error('Error releasing wake lock:', err);
    }
  }
}
```

1. **Activate Wake Lock when workout starts:**

```javascript
// In your "Start Workout" button click handler
function startWorkout() {
  isWorkoutActive = true;
  requestWakeLock();
  
  // ... rest of your existing workout start code
}
```

1. **Release Wake Lock when workout ends:**

```javascript
// When workout completes
function completeWorkout() {
  releaseWakeLock();
  
  // ... rest of your existing completion code
}

// When user exits/stops workout
function stopWorkout() {
  releaseWakeLock();
  
  // ... rest of your existing stop code
}
```

1. **Handle page visibility changes:**

```javascript
document.addEventListener('visibilitychange', async () => {
  if (document.visibilityState === 'visible' && isWorkoutActive) {
    await requestWakeLock();
  }
});
```

#### Browser Compatibility Fallback:

```javascript
// Check if Wake Lock is supported
if (!('wakeLock' in navigator)) {
  // Show notification to user
  alert('Your browser does not support keeping screen awake. Please adjust your device settings to prevent screen timeout during workouts.');
}
```

## PROBLEM 2: CANNOT DELETE/REMOVE EXERCISES ⚠️

### Current Issue:

- Once exercises are added to the workout, users cannot remove them
- No delete button or remove functionality exists

### Required Solution:

Add delete functionality with confirmation dialog.

#### Implementation Steps:

1. **Add delete button to each exercise in the list:**

```javascript
// When rendering each exercise in the workout list
function renderExerciseList() {
  const exerciseListHTML = selectedExercises.map((exercise, index) => `
    <div class="exercise-item" id="exercise-${index}">
      <div class="exercise-info">
        <h3>${exercise.name}</h3>
        <p>${exercise.sets} sets × ${exercise.reps} reps</p>
      </div>
      <button class="delete-btn" onclick="confirmDeleteExercise(${index})" aria-label="Delete exercise">
        <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
          <path d="M3 6h18M19 6v14a2 2 0 01-2 2H7a2 2 0 01-2-2V6m3 0V4a2 2 0 012-2h4a2 2 0 012 2v2"/>
          <line x1="10" y1="11" x2="10" y2="17"/>
          <line x1="14" y1="11" x2="14" y2="17"/>
        </svg>
      </button>
    </div>
  `).join('');
  
  document.getElementById('exercise-list').innerHTML = exerciseListHTML;
}

function confirmDeleteExercise(index) {
  const exercise = selectedExercises[index];
  
  if (confirm(`Are you sure you want to remove "${exercise.name}" from your workout?`)) {
    deleteExercise(index);
  }
}
```

1. **Create delete exercise function:**

```javascript
function deleteExercise(index) {
  // Remove exercise from array
  selectedExercises.splice(index, 1);
  
  // Update UI
  renderExerciseList();
  
  // Update exercise counter
  updateExerciseCounter();
  
  // Show feedback
  showNotification(`Exercise removed successfully`);
  
  // If no exercises left, show empty state
  if (selectedExercises.length === 0) {
    document.getElementById('exercise-list').innerHTML = '<p class="empty-state">No exercises added yet. Add some exercises to start your workout!</p>';
    document.getElementById('start-workout-btn').disabled = true;
  }
}
```

1. **Add notification function for feedback:**

```javascript
function showNotification(message) {
  const notification = document.createElement('div');
  notification.className = 'notification';
  notification.textContent = message;
  document.body.appendChild(notification);
  
  setTimeout(() => {
    notification.classList.add('show');
  }, 10);
  
  setTimeout(() => {
    notification.classList.remove('show');
    setTimeout(() => notification.remove(), 300);
  }, 2000);
}
```
