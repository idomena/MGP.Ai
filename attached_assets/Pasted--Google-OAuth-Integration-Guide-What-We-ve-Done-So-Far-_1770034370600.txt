## 🔧 Next Steps - Integration:

### Option 1: If You Have an Existing server.js

1. **Add to the TOP of your server.js:**
```javascript
const session = require('express-session');
const passport = require('./auth');
const { router: authRouter, ensureAuthenticated } = require('./authRoutes');
```

2. **Add BEFORE your routes (after app = express()):**
```javascript
// Session middleware
app.use(session({
  secret: process.env.SESSION_SECRET,
  resave: false,
  saveUninitialized: false,
  cookie: { 
    secure: process.env.NODE_ENV === 'production',
    maxAge: 24 * 60 * 60 * 1000
  }
}));

// Passport middleware
app.use(passport.initialize());
app.use(passport.session());

// Auth routes
app.use(authRouter);
```

3. **Add Supabase credentials to Secrets:**
   - Go to Replit Secrets
   - Add: `SUPABASE_URL` (your Supabase project URL)
   - Add: `SUPABASE_ANON_KEY` (your Supabase anon/public key)

4. **To protect any route, add `ensureAuthenticated` middleware:**
```javascript
app.get('/api/workouts', ensureAuthenticated, (req, res) => {
  // Your code here
  // Access user with: req.user
});
```

### Option 2: If You're Starting Fresh

1. Use `server-example.js` as your main server file
2. Rename it to `server.js` or whatever your main file is
3. Add your existing routes to it

## 🔒 Protect Your Routes:

Any route that should require login, add `ensureAuthenticated`:

```javascript
app.get('/api/user/workouts', ensureAuthenticated, async (req, res) => {
  // req.user contains the logged-in user's data
  const userId = req.user.id;
  
  // Fetch user's workouts from Supabase
  const { data, error } = await supabase
    .from('workout_completions')
    .select('*')
    .eq('user_id', userId);
    
  res.json(data);
});
```

## 🆘 Troubleshooting:

### Error: "Cannot find module './auth'"
- Make sure `auth.js` is in the same directory as your server file
- Or update the path: `require('./path/to/auth')`

### Error: "SUPABASE_URL is not defined"
- Go to Replit Secrets
- Add SUPABASE_URL and SUPABASE_ANON_KEY

### Login redirects to error page
- Check that your Google redirect URI matches exactly:
  `https://mgp-ai.replit.app/auth/google/callback`
- Make sure all secrets are added correctly

### Session not persisting
- Make sure SESSION_SECRET is set in Replit Secrets
- Check that cookie settings are correct
