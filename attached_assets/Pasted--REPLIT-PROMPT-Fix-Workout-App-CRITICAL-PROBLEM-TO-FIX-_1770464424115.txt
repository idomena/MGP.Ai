# REPLIT PROMPT: Fix Workout App

## 🚨 CRITICAL PROBLEM TO FIX

When user creates a workout and selects "Chest", they are seeing exercises from BACK, SHOULDERS, and other muscle groups mixed in. This is WRONG.

**Example of the problem:**
- User selects "Chest" muscle group
- User sees: Bench Press (Chest) ✓ CORRECT
- User sees: Pull-ups (Back) ✗ WRONG! 
- User sees: Squats (Legs) ✗ WRONG!

## ✅ CORRECT BEHAVIOR

When user selects "Chest" → Show ONLY chest exercises
When user selects "Back" → Show ONLY back exercises
When user selects "Chest + Shoulders" → Show ONLY chest AND shoulder exercises

## 🔧 THE FIX

### Check your exercise filtering code:

**WRONG CODE (don't do this):**
```javascript
// This shows ALL exercises regardless of selection
const exercises = await supabase
  .from('exercises_library')
  .select('*');
```

**CORRECT CODE (do this):**
```javascript
// Filter by selected muscle groups ONLY
const exercises = await supabase
  .from('exercises_library')
  .select('*')
  .in('muscle_group', selectedMuscleGroups); // ← This is the key!
```

### Example:
```javascript
// User selected: ['chest', 'shoulders']

const { data: exercises } = await supabase
  .from('exercises_library')
  .select('*')
  .in('muscle_group', ['chest', 'shoulders']); // Show ONLY chest and shoulder exercises

// Result: Bench Press ✓, Shoulder Press ✓, Pull-ups ✗ (filtered out)
```
