## The core mistake (common, don’t worry)

The system is likely doing one of these on app load:

* Creating today’s workout **after** checking skip logic
* Or checking skip logic **before creating today’s row**
* Or using UTC time while you expect local time

Any of these = instant orange circle.

## ✅ Correct order of operations (THIS IS CRITICAL)

Every app load MUST follow this order:

### STEP 1 — Determine today (once)

⚠️ This must happen **BEFORE any skip logic**

```
IF current_time >= 00:01

```

❌ Never skip `workout_date === today`
