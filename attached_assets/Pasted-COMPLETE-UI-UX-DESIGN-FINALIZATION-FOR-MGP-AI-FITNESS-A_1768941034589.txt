SECTION 1: HOMEPAGE - FITNESS JOURNEY PATH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INFINITY JOURNEY CONCEPT:
- The workout journey should feel INFINITE - no visible end
- Create a continuously flowing path that suggests endless progression
- Users should feel like they're on an ongoing fitness journey, not a finite program

PATH DESIGN REQUIREMENTS:

1. INFINITE SCROLL EFFECT:
   - Path extends beyond the screen (scrollable)
   - Smooth infinite scroll animation
   - Path continues "infinitely" downward
   - Fade effect at bottom suggesting more to come
   - No hard stop or "end" visible
   - Journey feels endless and motivating

2. PATH FLOW PATTERN:
   - Smooth, natural S-curve or flowing pattern
   - NOT a straight line down
   - Organic, river-like flow
   - Path should feel like a journey through terrain
   - Curves should be gentle and natural
   - Width of path: consistent throughout

3. WORKOUT CIRCLES ON PATH:
   - Circles positioned DIRECTLY ON the path line
   - Path line flows THROUGH the center of each circle
   - Circles are part of the path, not floating beside it
   - Spacing: 120-150px between circles
   - Size: 80px diameter for circles
   - Numbered circles: Day 1, Day 2, Day 3... infinitely

4. CIRCLE STATES & VISUAL DESIGN:

   STATE 1 - COMPLETED (Past workouts):
   - Green/teal gradient background
   - White checkmark icon inside
   - Slightly smaller and less prominent
   - Lower opacity (70%)
   - No animation on hover
   - Path behind is filled/completed color

   STATE 2 - TODAY (Current workout):
   - LARGE and prominent (100px diameter)
   - Bright purple/blue gradient with glow effect
   - Pulsing animation (subtle heartbeat effect)
   - "TODAY" badge above circle (green pill-shaped)
   - Play icon inside (white)
   - Path line highlighted/glowing here
   - Drop shadow for elevation
   - Tap to start workout

   STATE 3 - UPCOMING (Future workouts):
   - Gray/dark background
   - Lock icon inside
   - Slightly faded (60% opacity)
   - No glow or animation
   - Path ahead is dotted/dashed line
   - Not clickable (disabled state)

5. PATH LINE DESIGN:
   - Behind completed circles: Solid gradient line (green to purple)
   - At current workout: Glowing, animated line
   - Ahead of current: Dashed/dotted gray line
   - Line width: 6px
   - Smooth gradient transitions between states
   - SVG path for smooth curves

6. WORKOUT INFORMATION ON CIRCLES:
   - Day number inside circle
   - On hover/tap: Show workout name tooltip above circle
   - Example: "Day 15 - Back + Front hand"
   - Keep it minimal - don't clutter the journey view

7. HEADER STATS (Top of Page):
   - Clean stats bar with frosted glass effect
   - Three cards side by side:
     * Workouts: "16/∞" (infinity symbol, not a number)
     * Streak: "12 🔥" (fire emoji)
     * XP: "2,840 ⚡" (lightning emoji)
   - Semi-transparent background
   - Rounded corners
   - Subtle drop shadow

8. SCROLLING BEHAVIOR:
   - Auto-scroll to "TODAY" workout when page loads
   - Smooth scroll animation (1 second duration)
   - TODAY circle should be centered on screen
   - User can scroll up to see past workouts
   - User can scroll down to preview upcoming (but they're locked)

9. ANIMATIONS:
   - Path draws in from top to bottom on first load (SVG animation)
   - Circles fade in sequentially (cascade effect)
   - TODAY circle pulses gently (1.5s interval)
   - Smooth transitions between all states
   - Parallax effect on scroll (path moves slower than background)

10. BACKGROUND:
   - Dark gradient background (#0a0e27 to #1a1a2e)
   - Subtle animated dots/particles in background
   - Creates depth and movement
   - Don't distract from the path

11. MOBILE RESPONSIVE:
   - Path should scale to screen width
   - Circles slightly smaller on mobile (60px)
   - Touch-friendly sizes (min 44px tap target)
   - Smooth scroll on mobile
   - Performance optimized (60fps animations)

FINISH ALL THE CORNERS & DETAILS:

1. CONSISTENT BORDER RADIUS:
   - Small elements (buttons, chips): 12px
   - Cards: 16px
   - Modals/sheets: 24px
   - Never use sharp corners (0px)
   - Consistent rounding creates polish

2. SHADOWS & ELEVATION:
   - Level 1 (cards): box-shadow: 0 2px 8px rgba(0,0,0,0.15)
   - Level 2 (modals): box-shadow: 0 8px 24px rgba(0,0,0,0.25)
   - Level 3 (floating elements): box-shadow: 0 12px 48px rgba(0,0,0,0.35)
   - Consistent shadows create depth hierarchy

3. SPACING SYSTEM:
   - Use consistent spacing scale:
     * 4px (tiny)
     * 8px (small)
     * 16px (medium)
     * 24px (large)
     * 32px (extra large)
     * 48px (huge)
   - Never use random spacing like 13px or 27px
   - Creates visual rhythm

4. TYPOGRAPHY:
   - Headings: Bold, large (24-32px)
   - Body text: Regular, readable (16px)
   - Labels: Medium, smaller (14px)
   - Captions: Light, tiny (12px)
   - Consistent font weights: 400, 500, 700
   - Line height: 1.5 for readability

5. COLOR CONSISTENCY:
   - Primary gradient: Purple (#8B5CF6) to Blue (#3B82F6)
   - Success: Green (#10B981)
   - Warning: Yellow (#F59E0B)
   - Error: Red (#EF4444)
   - Background dark: #0a0e27
   - Background darker: #1a1a2e
   - Text primary: White (#FFFFFF)
   - Text secondary: Gray (#9CA3AF)
   - Never introduce random colors

6. ANIMATIONS EVERYWHERE:
   - All buttons: Scale on tap (scale: 0.95)
   - All cards: Hover scale + glow
   - All page transitions: Smooth fade + slide
   - All modals: Slide up from bottom
   - Loading states: Skeleton screens or spinners
   - Success actions: Confetti or checkmark animations
   - Duration: 200-300ms (feels snappy)
   - Easing: ease-in-out (smooth)

7. LOADING STATES:
   - Skeleton screens while data loads
   - Shimmer effect on skeletons
   - Spinners for quick actions
   - Never show blank screens
   - Always give feedback

8. EMPTY STATES:
   - Friendly illustrations
   - Helpful text: "No workouts yet. Let's get started!"
   - Call-to-action button
   - Never show just "No data"

9. ERROR STATES:
   - Friendly error messages
   - Suggestion for what to do
   - Retry button
   - Never show technical error codes

10. ACCESSIBILITY:
   - All tap targets min 44px x 44px
   - High contrast text (WCAG AA compliant)
   - Focus states on all interactive elements
   - Proper ARIA labels
   - Keyboard navigation support
   - Screen reader friendly

11. PERFORMANCE:
   - 60fps animations (use CSS transforms, not position)
   - Lazy load images
   - Optimize bundle size
   - Fast page transitions
   - No janky scrolling

12. MICRO-INTERACTIONS:
   - Button press feedback
   - Swipe gestures where appropriate
   - Pull-to-refresh on lists
   - Haptic feedback (mobile)
   - Sound effects (optional, subtle)
