# ✅ The CORRECT rules (what you want)

Let’s define **one golden rule** first:

> **Only ONE workout can be active per day.
> Tomorrow’s workout must NEVER start today.**

---

## 🧠 Canonical workout rules (this is the model)

### 1️⃣ Daily workout ownership

* Each workout belongs to a **specific calendar day**
* Example:

  * 2026-02-06 → Workout A
  * 2026-02-07 → Workout B

You **cannot start tomorrow’s workout today**, even if today is completed.

---

### 2️⃣ Status rules (very important)

Each daily workout has exactly ONE status:

* `not_started`
* `completed`
* `skipped`

❌ There is NO “auto-completed” during the day
❌ There is NO instant skipping when app loads

---

### 3️⃣ Completion rules

* If the user **clicks “Complete workout” today**
  → today’s workout = `completed`

* After completion:

  * User sees **rest / recovery state**
  * Tomorrow’s workout is **locked**
  * UI should say something like:

    > “Great job. Come back tomorrow 💪”

---

### 4️⃣ Rest day behavior

* A rest day is still a **day entry**
* It is NOT auto-completed
* The user can:

  * Replace it manually (change workout)
  * Or do nothing

If user does nothing → see rule 5.

---

### 5️⃣ Midnight rule (THIS IS KEY)

At **00:01** (server time):

* If today’s workout status = `not_started`
  → mark as `skipped`

* If status = `completed`
  → leave as `completed`

Then and ONLY then:
➡️ Tomorrow’s workout becomes available

✅ This is the **only automatic transition**
